# Usage

1. Create and activate a venv:
   python3 -m venv venv
   source venv/bin/activate

2. Install test deps (optional):
   pip install -r requirements.txt

3. Run the CLI:
   python3 main.py

4. Menu options:
   - Set alarms (HH:MM:SS)
   - View scheduled alarms (shows id)
   - Cancel (use id)
   - View logs (alarm_log.txt)
